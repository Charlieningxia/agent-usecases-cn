不会写代码，4 小时不到让智能体搭一个全家每天用的家务应用

作者/出处：Luke McAlpine
原文：https://www.linkedin.com/posts/luke-m-nz_im-not-a-developer-with-under-4-hours-of-activity-7524026837052710912-6ggw
日期：2026-11-05 · 工具：Claude Code
成本：Claude Code 订阅档位价原文未提及，复现前须自行核对；自托管、无额外基础设施费用说明 · 耗时：作者本人 <4 小时；读者照做约半天（非 30 分钟）

一句话

作者不是开发者，是搞基础设施的（服务器、网络、防火墙、备份）；18 岁的儿子不做家务、唠叨没用，他花不到 4 小时自己的时间、让 Claude Code 写了一个 25,000 行的家务应用——8 天后全家每天在用，儿子“基本”在做家务，连胜计数起了作用。

原作者怎么做的

  1. 从一个具体、烦人的家庭问题出发：18 岁儿子不做家务，唠叨无效；目标不是“学编程”，是“让家务被做完”。
  2. 用 Claude Code 从零搭建：作者本人没写一行代码；应用功能按家庭实际需要定：儿子打勾的家务、需家长批准才发钱的有偿任务、家庭聊天、日历、购物清单、备忘。
  3. 要求工程化交付：70 个 pull request、300+ 自动化测试；作者按基础设施的习惯验收（能跑测试、能回滚），而不是只看界面。
  4. 按家庭隐私部署：自托管、只在新西兰本地运行、异地备份、每次登录都有记录；家里的安全摄像头画面只给家长看。
  5. 用机制而不是唠叨驱动行为：连胜计数（streak）让儿子为了不断连而做家务——作者原话：“Is he doing his chores? Mostly. The streak counter is doing a lot of the work.”

结果

  • 25,000 行应用已上线，8 天后全家每天在用；作者本人耗时 <4 小时，零行手写代码
  • 70 个 pull request，300+ 自动化测试
  • 儿子做家务“基本”完成（作者原话 Mostly，未给完成率数字）；连胜计数在起作用
  • 自托管、新西兰本地运行、异地备份、每次登录有记录

中国读者怎么迁移

这是“为一个具体家庭问题造应用”的模板，不只适用于家务：老人吃药提醒、孩子作业打卡、合租账单分摊，都可以套同一个做法——问题要具体到一个人、一件烦心事；功能清单先写清再动手；验收标准是“家里人每天在用”，不是“代码写得漂亮”。Claude Code 在国内的访问与订阅方式不同，成本按自己的订阅价算；自托管可用家里的旧电脑或 NAS，异地备份不要省。
