一句话

一位非全职开发者用韩语向 Claude Code 描述需求，智能体完成了规划、编码、部署、调试、配图乃至短视频，2 天做出一个每小时自动重建的资讯站，服务器账单 $0。

原作者怎么做的

  1. 用自然语言（韩语）描述想要什么，Claude Code 负责规划、编码、部署、调试、图片和短视频。
  2. 定下 $0 约束并让智能体照此选型：托管用 GitHub Pages（纯静态 HTML）；登录、书签、访问计数、推送订阅用 Cloudflare Workers + D1 免费档；“冰箱有什么能做什么菜”工具的识图用 Workers AI 上的公开视觉模型，每日设上限卡在免费额度内；数据源只用允许抓取的公开 RSS（券商研报、Upbit 公开加密 API、Google Trends RSS）；自动化用自己电脑上的 Windows 任务计划，每小时执行“采集→处理→构建→git push”。
  3. 新闻聚类踩过坑后改法：第一版用链式关联（A≈B、B≈C 就合并），把完全不同的两件事 A 和 C 并到了一起；改成“所有文章都与一篇种子文章对比”后修好。
  4. 给每篇文章打“verification signals”分而不是下事实裁决：交叉报道加分、具名信源 vs 匿名/社媒信源、标题里的数字和双引号引文是否在正文出现、同事件伤亡数字各家不一致就打旗；页面永远声明这只是阅读辅助，不是最终判断。
  5. 券商研报做成节点树：一篇研报 = 一个节点（机构、方向、目标价 old→new、理由标签），按个股汇总成“上涨理由 / 下跌理由”树。
  6. 搜索引擎优化顺手做了：RSS、sitemap 的 lastmod 只在内容哈希变化时更新、薄页面 noindex、JS 渲染页预渲染成静态 HTML——某页爬虫可见文本从 687 字符涨到 13,605 字符；还删掉了约 2,400 个无价值的多语言旧页。
  7. 把翻车现场也写出来了：一年前的无日期旧闻混进 RSS 被当成“今日报道”（修复：按 RSS→URL→页面元数据解析日期，丢掉 7 天前的，标记离谱的目标价跳变）；韩语标题里表强调的单引号被当成引文扣分（修复：只比对双引号）；生成的配图人物手部畸形（修复：只用人工检查过的图）。

中国读者怎么迁移

$0 架构里的 GitHub Pages、Cloudflare Workers 在国内直连不稳定，可换成：托管用 Vercel/Netlify 免费档或国内静态托管，任务计划用 GitHub Actions 的 cron（免费额度内）或一台旧电脑/软路由。RSS 数据源换成中文公开源（注意 robots 与版权）；韩语/中文的引号误判问题同样存在，verification signals 那套“只比对双引号”的教训可以直接抄。

风险与限制

  • 作者是非全职开发者但有一定技术基础，纯小白照做仍需一天左右熟悉部署流程。
  • $0 指服务器/API，域名与 Claude 订阅是另算的——不要把标题读成“全免费”。
  • 每小时全站重建对免费额度（Workers 请求数、构建分钟数）有消耗，页面量再大一个数量级可能要精简重建频率。
  • RSS 抓取务必遵守 robots.txt 与版权，商用前咨询法务；AI 生成的资讯摘要仍可能出错，verification signals 是辅助不是背书。
