作者/出处：Eric Wu
原文：https://aiandlife.substack.com/p/the-moving-line

一句话

一件拖了两年的私事，不一定非要等一个完美的现成产品：作者把近 40 小时中英混杂的私人录音交给 Claude——开车时口述目标、2 小时搭出一个单文件转录工具，4–6 小时跑完，总共花了约 $40，而同样体量的现成服务公开报价在 $400 到近 $5,000 之间。

原作者怎么做的

  1. 拖了两年没买：中英混杂的私人录音一直躺在待办清单上，现成方案要么贵得离谱、要么不合用；作者本职十年就是替公司做这类“买还是造”的判断。
  2. 换思路：2026 年初 Claude Cowork 上市后，作者决定这次不买、自己造——长途开车时全程语音向 Claude 口述目标，连“做成网页应用还是别的”都还没定。
  3. 定成单文件工具：讨论后定为“单个 HTML 文件 + 调转录服务 API”——不搭后端、不买新软件；搭建本身约 2 小时。
  4. 啃中英混杂这个硬点：不是普通语音转文字——要给 API 传参数，让它在英文与中文之间聚焦；作者花了大量时间反复测试，最终解决问题（测试与设计约 10 小时，作者自述期间可兼顾其他事、但切换注意力本身有成本）。
  5. 跑完并算账：近 40 小时录音跑转录 4–6 小时；API 约 $20 + Claude 月费 $20（作者注明月费还用于许多其他事，属分摊口径），合计约 $40；对照 Rev AI 按每分钟 $0.25 计约 $600、Sonix 按每小时 $10 计约 $400、Rev 人工按每分钟 $2 计近 $5,000。
  6. 第二例佐证同一判断：看到一个带粘性广告（关不掉、疑似想装恶意软件）的换皮逻辑谜游戏网页，作者向 Claude 描述后，17 分钟、2 条提示词就搭出可离线玩的同款（Kitty Logic）；但作者同时说明，公开版又花了许多真实小时做基建、修谜题、代码与安全评审——17 分钟是“给自己玩”的版本，不是发布版。

结果

  • 40 小时录音转录完成：自建约 $40 vs Rev AI 约 $600 / Sonix 约 $400 / Rev 人工近 $5,000（已节省，作者自述；对照为公开报价折算，非实付账单）

提示词结构

（按原文做法还原的“口述造工具”骨架，非原文逐字提示词）

```

先口述目标、不要先定形态：[我要解决什么] + [材料是什么样的：中英混杂私人录音]，让智能体先建议 [最简单的形态：单个 HTML 文件 + 现成 API]，而不是直接要一个完整应用。

卡在“不合用”的点上反复测：[中英混杂要传什么参数聚焦语言]，每轮测试只改一个变量，测到问题解决为止。

算账用公开价对照：[自建现金成本：API + 分摊月费] vs [现成服务公开报价 × 体量]，分摊的月费要写明分摊口径，不要写成“只花了 API 钱”。

先给自己用、再谈发布：[自己用的版本] 与 [公开版] 分开计时——公开版的基建、评审、安全成本要另算，不能拿 17 分钟去承诺发布。

```

中国读者怎么迁移

手头有大批录音、访谈、家庭老磁带要转文字的读者可以直接抄：先别买按分钟/小时计费的转录套餐——用“口述目标 + 单文件 + 转录 API”的路子，2 小时搭一个只属于自己的工具；中英混杂的要特别测“语言聚焦参数”，这是作者花时间最多的地方。国内读者换成本地转录 API 与模型时，价目与隐私条款要自己重核——作者专门确认过他的 API 商“不拿音频训练、不保留音频”，这一点照搬前必须自己验证，不能默认。

风险与限制

  • 对照是公开报价折算：$600/$400/$5,000 是作者按 Rev、Sonix 公开价 × 体量算的，不是他实付过的账单；“省了 $560–$4,960”要写成“比公开报价低”，不能写成“已到账”。
  • $40 是分摊口径：$20 Claude 月费作者自述还用于许多其他事；只算这一个任务的边际成本会更低，但把整月月费全算进来又会更高——引用时必须带上这个口径。
  • 维护责任在自己：作者自问“坏了怎么办”——API 一变、工具一坏，没客服可找，只能自己修；Claude 能帮忙，但没有“签了合同负责到底的人”。
  • 隐私与合规自己扛：私人录音可以自己玩；涉及他人数据、公司合规、税务这类“一错就是审计”的场景，作者自己也说会买现成软件——这条线要写清楚。
  • 测试时间不是零：2 小时是搭建，作者另花约 10 小时测试与设计；只宣传“2 小时搞定”会低估真实投入。
  • 与已发布案例的边界：本站已有“从零建东西”（零账单站点、Helm 应用）与“账单谈判”案；这篇是“为一次性私人任务造小工具、按公开报价算节省”，问题与算账方式都不同。
