一句话

做游戏不一定要先写三个月引擎：作者用一段话起手、一个“开到验真为止”的个人技能管住智能体，47 小时内让 Claude Code 交出一款能玩、有 100 波、有原声音乐与预告片的完整塔防游戏——人只负责短指令、看截图、做音乐与上线那几件机器干不了的事。

原作者怎么做的

  1. 一段话起手：2026-10-07 22:06 UTC，先让模型出“Laravel 主题塔防、玩法像 Bloons”的设计概念与规格——本来打算把规格交给 Codex；72 分钟后改主意，在 Claude Code 里敲了自家个人技能 /goal：让智能体把任务开到“验真完成态”才停。
  2. 规格先行、再分波次并行：主会话 + 歌曲会话两个顶层会话、27 个子智能体（主会话 22 个跑在 git worktree 里，分 4 波；4 个只读研究员；歌曲会话 1 个用 Fable 5.1 拍预告片素材）；主会话被压缩 3 次。
  3. 人只干四类事：发短指令（构建会话 96 条、中位 17 词，其中 52 条是智能体回合中途插话）、看截图与前后对比板做判断、亲手做音乐（Suno 上按 Claude 写的歌词与风格标签生成、桌面软件做 stem 与歌曲分析）、亲手上线（传预告片到 YouTube、买域名、接 Vercel）。
  4. 验真机制是“机器人玩 + 门禁”：确定性数据驱动引擎 + 机器人跑平衡门禁；浏览器内 AI 玩家走 19 个 WebMCP 工具（读状态、找位置、放塔、升级、开波、快进），每步以 toast 显示；测试 485 个 Vitest + 50 个 Playwright；产物体 8.49MB（规格预算 25MB）；标签化发布流水线，10 个版本从 v0.1.0 到 v0.6.3。
  5. 美术与音乐也走流水线：约 469 张 gpt-image-2 出图（374 张进资产流水线、预算 450 张；93 张概念图；2 次 README 头图尝试）；原声主题曲 + 两段循环 + 一支按节拍剪的代码渲染预告片（95.8 秒、1080p、30fps）；社区真人做“精英”与“客串明星”形象（Taylor Otwell、Nuno Maduro 等 8 位常规精英 + 5 位秘密精英，作者自己也是其中之一）。
  6. 失败也写进去了：全文附“哪里错了、由此生出的护栏”一节，并把仓库设为私有、所有片段按原文文件路径逐字贴出——作者说写给“人看与智能体复现”两用。
