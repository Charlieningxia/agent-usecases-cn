让 Claude Code + Higgsfield 复刻爆款视频：14 天 34 万观看

作者/出处：Vlad Pereira
原文：https://vladpereira.com/blog/one-month-recreating-viral-videos-with-ai
日期：2026-10-19（约；原文页未标发布日期，检索索引显示 20 天前；数据截至 2026-10-11） · 工具：Claude Code、 Higgsfield Genjutsu
成本：每条 119–182 Higgsfield credits（16–25 秒、720p）；Claude Code 随 Claude 付费档（Pro 起）；credit 未折算美元 · 耗时：一条复刻的生产流水线约数十分钟到数小时（含失败重跑）；读者照做需先备好真实参考照片集

一句话

作者 Vlad Pereira 用 Claude Code + Higgsfield 复刻爆款视频：9 月 27 日第一条 AI 复刻上线后 14 天，他的 Facebook 观看量从过去 12 个月的 51,076 涨到 340,427；微信视频号单条最高 1,775,142 播放、涨粉 3,599——但他自己先说了：观看不是信任，涨粉不等于赚钱。

原作者怎么做的

  1. 挑已经爆过的格式：不原创，先找一个已验证的爆款动作（原片），再加自己的 twist 复刻——作者称之为 Recreate + Twist Loop。
  2. 五步生产流水线（Claude Code 在他自己电脑上跑）：① 读原片——下载原视频、读时长与帧率、每秒抽一帧做 contact sheet，看清身体哪里重叠、AI 哪里容易翻车；② 建真实人脸参考集——Claude 扫了他电脑里的 4,404 张图，找出 277 张是他的，剔掉所有 AI 修过/滤镜过的照片（那会教坏模型），最后留 19 张实拍 + 12 张脸部裁切；③ 写人物表——按编号列他的特征，头发放第一位（模型总爱给他深色卷发），附上传文件清单与事后检查清单；④ 驱动 Higgsfield——Claude 打开 Genjutsu、上传参考视频与图片、写提示词，停在 Generate 按钮前先报成本，等他批准花钱、并由他本人点每张脸的授权确认屏；⑤ 像编辑一样验收——先查文字（AI 会写错招牌与歌词），再查脸、口型、手与衣服；Claude 抽帧、裁脸、拼并排对比图，一眼定夺。
  3. 分层运营：复刻带来触达；视频爆了之后再发一条“我是怎么做出来的”拆解，把好奇的人转成订阅者；不加脚本的一镜到底谈话视频（不用 AI）负责建立信任；产品放最后。
  4. 失败也记下来了：第一条雨衣测试把脸融化了，舞蹈棚测试把身体拉长了——失败案例与下一轮改了什么都写进了他的电子书。

结果

  • 已实现（作者自述，Dashboard 截图数据，未独立核实）：Facebook 12 个月 51,076 观看 → 首条复刻后 14 天 340,427 观看；净增粉丝 10 → 821；观看时长 1 小时 11 分 → 31 天 14 小时；单条最高：水果店不请舞者（10 月 9 日）119,484 观看
  • 微信视频号单条（Jean Phil 表情包人设雨中唱歌）1,775,142 播放、43,945 分享、+3,599 粉丝；Instagram 日触达 2–38 人 → 411–6,090 人
  • 成本实测：每条 119–182 credits（16–25 秒、720p），生成前按钮上即显示精确成本；Claude Code 随 Claude 付费档（Pro 起）；credit 未折算美元，成稿不写美元成本
  • 作者自己的提醒：第二周末 96.9% 的观看来自非粉丝——复刻的意义是破圈，陷阱也是破圈：陌生人笑了不等于认识你，没人会向不认识的人买东西；全文无收入数，成稿不写收入

中国读者怎么迁移

这是“用 AI 复刻已验证的爆款动作”的打法，不是从零想创意：先找一个已爆的格式，再加自己的 twist。能直接抄走的是五步流水线与验收清单——尤其是“参考集只用实拍、剔掉修图照”和“生成前先报成本、授权确认由人点”这两条。国内读者用即梦、可灵、Vidu 等同理，Higgsfield 的 credit 数仅供参考，成本要按自己用的工具重算。另注意：这套打法涨的是曝光与粉丝，作者自己说了——观看不是信任，涨粉不等于赚钱，别把它当成收入案例。
