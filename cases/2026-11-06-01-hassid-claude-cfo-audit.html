让 Claude 当你的 CFO：导一份银行流水，28 分钟审出一年省 $10,200

作者/出处：Ruben Hassid
原文：https://ruben.substack.com/p/cfo
日期：2026-11-06 · 工具：Claude（免费版够用）、 Gmail
成本：$0（作者原话：免费版够用）；Claude 订阅档位价原文未提及，复现前须自行核对 · 耗时：约 30 分钟上手；首份审计报告 Claude 用 28 分钟生成

一句话

不用把银行账号接给任何 AI：导一份 CSV 流水丢给 Claude，让它像 CFO 一样逐项审计——作者靠一封议价邮件把 Stripe 手续费从 2% 谈到 1%，自述一年省 $10,200。

原作者怎么做的

  1. 各银行账户导出交易 CSV（作者建议拉 12 个月，才能抓到按年续费的幽灵订阅）。
  2. 在电脑上按银行建文件夹，如 AIRWALLEX-PRO、REVOLUT-PERSO，把 CSV 分开放进去。
  3. 关掉 Claude 的 Memory 与数据训练开关，再把整个文件夹上传给 Claude（作者明确表示不信任把银行账号直连任何 AI，全程只用导出的 CSV）。
  4. 粘贴一封长提示词，让 Claude 按 5 步做 CFO 审计：清洗（统一格式、剔除自己账户间的转账、按金额和日期归并 Apple/Google/PayPal 等中间商代扣）→ 初览（收支、成本中心、每笔定期收费）→ 提问（停下来问 5–10 个澄清问题）→ 逐项审计（每个成本中心按 KEEP/WATCH/CUT 打分，另 hunt 幽灵订阅、重复扣费、涨价、手续费）→ 重新比价 + 行动清单（每项续费账单给出当天最优价与链接，每项 CUT 都附上取消邮件/议价话术）。
  5. 回答 Claude 的澄清问题，等 28 分钟拿到首份审计报告，固定成一页可回看的月度资金看板（每月追加新流水更新）。
  6. 按行动清单发邮件：Claude 找到收件方、写好邮件、只在 Gmail 里存为草稿，作者自己点发送——Stripe 那封就是这样发出的，另有 21 封议价/取消邮件同样只存草稿、人工发送。

结果

  • Stripe 手续费 2% → 1%，作者自述年省 $10,200（年化口径：费率下调后的预计年节省，非已到账现金；原文未附 Stripe 回复或账单截图）
  • Claude 共起草 21 封议价/取消邮件，全部存在 Gmail 草稿里，由作者人工逐封发送
  • 首份审计报告 Claude 用 28 分钟生成；作者称普通人每年约 $200–300 幽灵订阅可被同法抓出（该数字为作者一般性说法，非其本人实测）
  • 成本 $0：作者原话免费版够用

```

角色：[当我的 CFO，找出我所有亏钱的地方，按金额从大到小告诉我该砍、该留、该换、该重谈]。

输入：[各银行导出的 CSV 交易记录]，每家银行格式、币种、日期范围都不同，部分账户可能是公司账。

步骤 1 清洗：[逐文件读：银行、账户、币种、起止日期、笔数] → [并成一张总表：日期/账户/商户（清洗后）/金额/币种] → [剔除自己账户间的转账、还卡、换汇、退款，避免重复计] → [按金额+日期归并中间商代扣，让每笔隐藏订阅单独成行]。

步骤 2 初览：[全期与逐月：进账、出账、结余] → [成本中心从大到小] → [每笔定期收费的价格与下次扣费日]。

步骤 3 提问：[停下来问 5–10 个问题，只问会改变建议的]，等我回答再继续。

步骤 4 审计：[逐成本中心：月/年花费、趋势、是否正常、每家商户 KEEP/WATCH/CUT + 一句话理由、照做一年省多少] → [另 hunt：幽灵订阅、重复扣费、涨价、免费试用转付费、取消后仍扣费、手续费]。

步骤 5 重谈与行动：[每项续费账单：搜当天同款最优价，附价格、链接、查询日期] → [每项 CUT/切换：写好取消邮件、切换步骤、议价话术] → [行动清单：一行一项、年省金额、耗时，按省钱排序，最后给总数]。

规则：[每个数字必须来自我的文件或附链接的来源，是估算就明说]；[涉及税务或法律只提一句]；[绝不要密码或账号]。

```

中国读者怎么迁移

国内银行 App 同样支持导出交易流水（CSV/Excel），按银行分文件夹的做法直接可用；Claude 免费版在国内访问与支付方式不同，成本按自己的订阅价算，不要照抄 $0；Stripe 费率谈判是作者的生意场景，个人读者重点应放在幽灵订阅与重复扣费这两项——这是最容易复现的部分；每月追加流水更新看板的做法，换成自己的记账节奏即可。

风险与限制

  • 结果口径：$10,200 是作者自述的年化节省（费率下调后的预计值），邮件已发出但原文未附 Stripe 回复或账单截图，不得写成已到账现金；作者称普通人每年 $200–300 幽灵订阅只是一般性说法，不是他本人的实测数。
  • 演示口径：文中截图作者自承用的是假数据（“I won't show my bank accounts… so I made fake folders”，artifact 亦注明 fake data），截图里的数字不能当证据引用。
  • 隐私口径：只导 CSV、不接银行账号是作者的核心前提；上传前关 Memory 与数据训练开关，敏感文件不要放进任何会留存训练的对话。
  • 适用边界：费率谈判、供应商议价的结果因人因生意而异；Claude 给出的“正常水平”判断来自其训练数据，未必符合中国读者的消费结构。
  • 与已发布案例的边界：与已发布 2026-10-17-02 订阅审计不同任务（彼为单项取消拿回 $700，此为全账本 CFO 审计 + 费率重谈）；与已发布 2026-10-17-03 AT&T 账单谈判不同任务（彼为单张账单谈判，此为全账本审计后批量议价）；方法上是长提示词 + 多步会话 + 文件夹与 Gmail 工具调用，非单步问答生成。
