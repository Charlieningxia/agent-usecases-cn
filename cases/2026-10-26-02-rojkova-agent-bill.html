一句话

问“智能体一个月多少钱”没有标准答案，作者把自己的账单摊开：夜间常驻的个人智能体约 $150/月，产出值不该按“省了几小时”算，而该按“请人做要多少钱”算——但她同时明说，这个智能体并没有给她省时间，反而让她晚上干得更多了。

原作者怎么做的

  1. 先报自己的总账：约 $150/月，拆成两块——约 $100 是订阅费加夜间运行时烧掉的 API token，$30–60 是让智能体 24 小时在线的小云服务器。
  2. 对照市场价目解释为什么别人的数字从 $20 到 $15,000 都有：单任务智能体 token 成本每月 $15–180（引 Sybill 2026 拆解）；5–6 个智能体的个人组合优化后 $185–480/月、不优化 $500–2,000/月；Sybill CEO 的 6 智能体高自主组合 $7,000–15,000/月；面向真实客户的生产级业务智能体 $3,200–13,000/月。结论：成本随自主程度和用量涨，不随“聪明程度”涨。
  3. 点出三个账单驱动因素：一个任务不是一次调用——规划、搜索、阅读、起草、自查各算一次，通常 5–20 次调用；夜间常驻等于“按工作小时计费的承包商”，睡着也在花钱；最贵的一项是人的评审时间——作者头几周评审花的时间比 token 还贵，简报写好后才降下来，预算里必须留这一项。
  4. 给出四个降本杠杆（按影响排序）：模型分层（常规步骤走便宜模型、判断步骤走贵模型，作者认为这是 $185 与 $2,000 组合的分水岭）；批量处理（OpenAI 与 Anthropic 的批量 API 对非实时任务打五折，夜间任务正合适）；提示词缓存（Claude 缓存输入最高打一折，常驻简报几乎等于免费）；等一等（引 Forbes 数据：混合 token 单价从 2025 年初约 $18.40/百万降到 2026 年初约 $6.07/百万，同样的智能体每季度都在变便宜）。
  5. 换一把尺子算回报：作者明说“省时间这个角度是错的”——她晚上花的时间反而变多了，因为以前不值得花 $10,000 请人做的项目，现在值得花一个晚上做了。她今年的夜间智能体产出包括一个完整个人网站和一个可用的网络产品；按行业价目，单一个网站请人做约 $10,000–25,000（文案全包 $3,500–15,000；设计加搭建 $5,000–10,000、平均 $6,760；后续按小时计费文案 $85–160、设计约 $75、开发 $100–180）。作者同时承认：这只是“没收到的发票”，不是省下的现金。

结果

  • 个人账单：约 $150/月（约 $100 订阅 + token，$30–60 服务器）（已实现，作者自述；分项为约数，无收据贴出）
  • 产出：今年夜间智能体产出一个完整个人网站和一个可用网络产品（已实现，作者自述；网站无链接、无访问与收入数字）
  • 对比估算：单一个网站请人做约 $10,000–25,000（市场价目对比估算，非作者实付、非实省；作者年成本 $1,800 只是与之对照的标尺）
  • 反面结果：作者明说智能体没有给她省时间，晚上干活时间反而变多；头几周评审时间成本高于 token 成本（已实现，作者自述）
  • 新手起步价：$20/月 + 一晚上，在标准 Claude 或 ChatGPT 订阅内就能跑第一个智能体，不需要服务器与 API 账号；等智能体“用真实产出挣回成本”再升级到 $100 档（作者建议）

```

先定总账上限：[每月预算] = [订阅] + [token] + [服务器]，三项分开记，不记总数等于没记。

任务分层：[常规步骤 → 便宜模型] + [判断步骤 → 贵模型]；不分层就是最贵的组合。

夜间任务走批量：[非实时任务 → 批量 API]，能打五折的别按实时价跑。

常驻简报走缓存：[长期不变的简报 → 缓存输入]，别每轮重读。

评审时间入账：[每项产出 → 一次人工评审]，头几周评审时间可能比 token 贵，先留出这项再谈省钱。

回报换尺子：不算 [省了几小时 × 时薪]，算 [请人做要多少钱] − [智能体年成本]；且必须注明这是“没收到的发票”，不是省下的现金。

```

中国读者怎么迁移

国内读者可直接抄这套记账法：先用 $20 档订阅（或等价套餐）跑一个夜间任务一晚上，记下订阅、token、服务器三项分开的账；任务分层与批量、缓存三招在各家模型平台都有对应开关。注意作者的提醒：先别买服务器与 API 账号，等第一个智能体拿出真实产出再升级。

风险与限制

  • 账单是约数不是收据：$150 拆成约 $100 与 $30–60 两块，无账单截图；市场价目引自 Sybill、Forbes 等二手来源，引用时必须保留“引述”属性。
  • 网站对比价是估算：$10,000–25,000 是行业价目区间，不是作者收到的报价，更不是省下的现金；网站本身无链接、无访问量与收入数字佐证。
  • 作者自认没省时间：这篇的价值在成本透明与“换尺子算账”，不在省时；拿它当“省时间案例”讲就是歪曲原文。
  • 文末带货：作者在文末推广自己的免费入门手册《Your First AI Agent》；方法本身不依赖该手册，引用时把方法与推广分开。
  • 价格会变：token 单价、批量折扣、缓存折扣均以各平台当时价目为准，作者引用的 2025–2026 年价格走势不构成未来承诺。
