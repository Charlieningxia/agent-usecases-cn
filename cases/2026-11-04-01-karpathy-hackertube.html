让智能体做视频发现站：约 2 小时，6,454 个视频上线

作者/出处：Andrej Karpathy（原文署名 karpathy；全名按公开身份链，见候选总表说明）
原文：https://karpathy.bearblog.dev/hacker-tube/
日期：2026-10-31 · 工具：Claude Code（Mac 桌面 App）、 Opus 5.5（Medium effort）、 Sonnet（Workflow 内过滤与打标签）、 Hacker News 评论公开数据、 Google Cloud YouTube API、 VPS
成本：VPS 与域名费用原文未给；Claude Code 订阅档位价原文未给，复现前须自行核对，订阅价若超 $50/月须显眼标注 · 耗时：作者自述约 2 小时做出可上线版本；读者照做自己的版本约半天（含申请 API key、开 VPS、买域名）

一句话

不想看算法推来的“标题党墙”，就让智能体把 Hacker News 上 2007–2026 年被推荐过的 YouTube 视频翻出来，做成一个干净的视频发现站：6,454 个视频、150 个主题，数据还能导出给自己的智能体复用。

原作者怎么做的

  1. 提需求，不写代码：作者在周六早上对 Opus 5.5 说，要一个“按 Hacker News 推荐做的 YouTube 克隆”，之后只和 Claude 对话，不再亲自读写代码、跑终端命令。
  2. 智能体拉数据并过滤：Claude Code 下载全部 Hacker News 评论（43M 条，2007–2026），过滤去垃圾，在 Workflow 里用 Sonnet 过一遍，筛出约 40,000 条“推荐了某个 YouTube 视频”的评论，最终落到 6,454 个视频、150 个主题。
  3. 智能体建站上线：用 YouTube 风格界面包装这些视频，改用 50% 缩略图代替上传者原缩略图，做无账号的本地会话推荐与键盘快捷键；作者只亲手做了 3 件事：去 Google Cloud 界面申请 YouTube API key、开一台 VPS、买域名。
  4. 智能体接管运维：把 VPS 的 IP 交给 Claude，让它更新、部署、加固、优化代码，全程由智能体执行。
  5. 数据开放复用：站点提供数据导出，读者可以把导出交给自己的智能体，照着做一个自己的版本。

结果

  • 6,454 个 YouTube 视频、150 个主题，来自约 40,000 条推荐评论（已实现，live 站可核）
  • 数据集可免费下载（作者称 17.8 MB，ODC-By 1.0；主路未下载校验，复现时以站点实际文件为准）
  • 约 2 小时做出可上线版本（作者自述，非独立计时；作者自述其间还在 Claude 干活的间隙做别的，体感像“组队”）

```
收尾：[数据导出]，让下一个智能体能直接复用这份清单。

```

中国读者怎么迁移

不一定复刻 Hacker News：把数据源换成你自己常看的中文社区公开推荐（如某个论坛的精华帖、公开合集），同样是“下载公开数据 → 过滤 → 判定推荐 → 建站”；国内网络与模型接入、YouTube API 可用性不同，成本按自己的 VPS、域名与 API 账单算，不要照抄任何美元数；43M 条全量数据量级很大，个人复现建议先从小样本（如某一年、某一个主题）起步。

风险与限制

  • 成本口径：VPS、域名、Claude Code 订阅档位价原文均未给，复现总成本未知；订阅价若超 $50/月须显眼标注。
  • 结果口径：6,454 个视频是产出数，不是省时/省钱数；“约 2 小时”为作者自述，未独立计时。
  • 准确性：视频标签与简介由 Claude 生成，原文未给抽查准确率，不能默认每个标签都对；上线前应抽查。
  • 合规注意：使用 YouTube API 与公开评论数据须遵守平台条款；下载与再发布他人视频元数据前先核对许可。
  • 与已发布案例的边界：与已发布 2026-10-20-05 HN 招聘数据案不同题（彼为招聘数据分析，此为视频发现站）；与已发布“用智能体建站”类案例不同——本篇的关键是“全量公开评论过滤成推荐清单 + 数据导出可复用”。
