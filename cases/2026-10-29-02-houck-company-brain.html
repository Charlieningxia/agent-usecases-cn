让智能体先审计公司账本再谈省钱：砍掉 $425,724 年支出，分项、替代成本与回本期全摊开

作者/出处：Michael Houck
原文：https://thefoundingjourney.substack.com/p/how-ai-saved-me-425k
日期：2026-10-16 · 工具：Hermes（Nous Research 的 agent 系统）、 公司大脑（feeds + brain + agent + harness 四件套）、 Mac Mini（作者自述云端托管亦可）
成本：经常性替代成本 $5,482/月；一次性替代 $11,108；一次性新建 $37,467；Hermes 与模型本身的单价原文未拆分 · 耗时：审计一步（列全公司事项 + 让智能体对账本）一天可启动；全套公司大脑需数周，非一日完成

速览卡

  • 分类：省钱账单
  • 结果：审计前 12 个月运营支出约 $1.12M；首月砍掉年化支出 $425,724（外包 $250,572 / 服务 $131,160 / 软件 $43,992）；扣掉经常性替代成本后净省 $29,995/月，一次性投入不到 2 个月回本；2.5 个月近 6,000 次提交、提交量 17 倍、代码行 7 倍（作者自述的产出量换算，平均提交变小）
  • 状态：作者自述未经审计
  • 成本：$5,482/月经常性 + $48,575 一次性（$11,108 替代 + $37,467 新建）
  • 耗时：审计一天可启动；全套数周

一句话

省钱的第一步不是上智能体，而是先让智能体把账算清楚：作者用“公司大脑 + 一层 agent”审计自家公司，首月砍掉年化 $425,724 支出——但他把替代成本也摊开了：每月还要花 $5,482，净省 $29,995/月，不到 2 个月才回本。

原作者怎么做的

  1. 先定“人还该干什么”：作者列出自己现阶段不愿让 AI 替代的工作，再列出公司全部事项——每项花多少时间、多久一次、是规则型还是需要判断。
  2. 让 agent 对账本：用 Hermes（Nous Research 的 agent 系统）跑公司账目，算出每项实际支出；结论是近 40% 的支出理论上可被结构良好的 agent 公司大脑系统砍掉。
  3. 砍掉的三类（年化）：外包 $250,572（59%）、服务 $131,160（31%）、软件 $43,992（10%），合计 $425,724。作者明说裁撤有人的代价：“对团队成员说再见从来不好受，哪怕与工作质量无关”。
  4. 把替代成本也列出来：经常性 $5,482/月；一次性替代 $11,108；一次性新建 $37,467；净省按经常性口径为 $29,995/月，一次性投入不到 2 个月回本。
  5. 搭四件套系统（作者称“ straightforward”）：

- feeds：每天公司新信息全自动流入——会议记录、Slack、邮件、决策等；

- brain：全公司上下文的家——决策日志、团队成员人脉图谱，cron 把信息路由到正确位置；

- agent：基于 brain 上下文主动与被动干活的一层，作者用 Hermes；

- harness：公司专属的 .md 文件库，告诉 agent 每项任务该怎么做；Hermes 会自己建技能，也可指定（作者曾让它花几小时爬 Airbnb 与 Linear 学设计，之后设计质量才过关）。

  1. 产出量变化（作者自述的换算，非质量结论）：2.5 个月近 6,000 次提交，相对此前同期提交量 17 倍、代码行 7 倍，作者据此称“10 倍交付速度”——但他自己也注明平均提交变小了。

结果

  • 年化削减 $425,724：外包 $250,572 / 服务 $131,160 / 软件 $43,992（作者自述，未经审计）
  • 净省 $29,995/月（经常性口径）；一次性投入 $48,575，不到 2 个月回本（作者自述，未经审计）
  • 2.5 个月近 6,000 次提交、提交量 17 倍、代码行 7 倍（作者自述；产出量非质量，平均提交变小作者已注明）
  • 审计前 12 个月运营支出约 $1.12M（作者自述，未经审计）

提示词结构

（按原文做法还原的审计骨架，非原文逐字提示词）

```

先定边界再算账：[人现阶段不愿让 AI 替代的工作] 单独列出，不进削减池。

列全事项：[每项工作] + [耗时] + [频率] + [规则型还是判断型]，再让智能体对 [账本] 逐项算支出。

分三类报数：[外包] / [服务] / [软件]，每类给年化金额与占比，不只报总数。

替代成本必须同表列出：[经常性/月] + [一次性替代] + [一次性新建]，算 [净省/月] 与 [回本月数]，不报毛省。

系统四件套：[feeds 自动流入] + [brain 决策日志与人脉图谱] + [agent 一层] + [harness .md 技能库]，技能不够就指定让它学（爬标杆学设计是作者的实例）。

产出量要带脚注：[提交量倍数] + [代码行倍数] + [平均提交变小]，不把行数当质量。

```

中国读者怎么迁移

个人与小团队读者能直接抄的是“审计一步”，不是全套大脑：今天列出自己全部经常性支出（外包、订阅服务、软件），让智能体逐项对账、标出“规则型且低频判断”的项，先砍软件与服务类（作者账里软件只占 10%，大头在外包与服务，别指望只砍订阅就省出大数）。全套大脑适合已有团队与多系统数据源的公司：feeds 要接会议、Slack、邮件与决策记录，harness 要写成 .md 技能库，作者的工期是数周加近 6,000 次提交量级的折腾，不是一天能抄完的。国内读者还要注意：裁撤外包与服务涉及合同与人员，省下的数要扣掉替代成本与过渡期人工再报。

风险与限制

  • 作者自述未经审计：全部金额为单家公司自报，无第三方核查；“10 倍交付速度”是作者对提交量与代码行的换算，不是质量或收入结论。
  • 全套需数周：审计一天可启动，但 feeds + brain + agent + harness 全套是数周工程；Mac Mini 与云端托管的运行成本、Hermes 与模型单价原文未拆分，$5,482/月是合计口径。
  • 销售漏斗须披露：原文两次推作者 10 月 29 日 13:00 EST 的免费“公司大脑”工作坊（hockeystickstudio.com），文末另有会员与多项自家服务引流；引用时不把工作坊报名写成案例结果。
  • 与已发布案例的边界：本站已有订阅审计（2026-10-17-02）与 AT&T 账单谈判（2026-10-17-03），那两篇是单项账单；这篇是公司级全量审计 + agent 系统，分项与替代成本齐全，问题不同。
