让 Claude Code 审计全部基建账单：一个月几乎省下 $34,000

作者/出处：Pieter Levels
原文：https://x.com/levelsio/status/2117694259558293692
日期：2026-11-03 · 工具：Claude Code
成本：Claude Max 20x $200/月（审计后降至 $100/月），超 $50/月线，须显眼标注 · 耗时：一次性审计，数小时可跑完；逐项切换另计

一句话

Pieter Levels 让 Claude Code 通读他全部生意的基础设施账单，逐项找出可省的钱：视频模型与 GPU 路由省 $29,000/月、服务器合并省 $3,000/月、备份与存储策略省 $1,500/月、域名清理与 Claude 套餐降档再省约 $218/月——合计几乎 $34,000/月，他称总支出已降到约 $300/月（不含 Photo AI）。

原作者怎么做的

  1. 把全部基建账单交给 Claude Code：GPU、服务器、备份、对象存储、域名、Claude 订阅——让它逐项审，找出每一处可省的钱。
  2. 视频模型与 GPU 路由（省 $29,000/月）：GPU 账单 $36,000/月→$7,000/月，部分转 Google Cloud 积分与 Sume。
  3. 服务器合并（省 $3,000/月）：取消 DigitalOcean 与 Linode，全部转 Hetzner。
  4. 备份与存储策略（省约 $1,500/月）：Backblaze B2 无限版本保留改为 30 天，$1,200/月→$26/月（约 50 倍便宜）；R2 生命周期策略，$1,200/月→$800/月。
  5. 域名与订阅（省约 $218/月）：Claude 分析 Cloudflare 域名注册，清理未用域名，省 $118/月；Claude 套餐从 Max 20x $200/月降至 $100/月，省 $100/月。
  6. 对外报出总数：分项合计 $33,718/月，作者称“几乎 $34,000/月”，总支出已降到约 $300/月，成本比去年砍了 90%。

结果

  • 已节省（作者自述，分项前后对照，X 原帖逐字核实）：分项合计 $33,718/月，与作者所称“几乎 $34,000/月”一致；作者称总支出已降到约 $300/月、比去年砍 90%。
  • 数字口径（成稿须显眼写清）：① GPU 省 $29,000/月部分来自 Google Cloud 积分——积分可能是一次性的，未必每月复现；② “总支出约 $300/月”不含 Photo AI，含 Photo AI 后总费用约 $8,000/月（$7,000 GPU + $800 R2）；③ 该帖引用了作者 9 月 9 日约 $25,000/月节省的旧帖，两者不可重复相加；④ 全部数字为作者自述，未独立核实。

提示词结构

（按原文做法转写；原文为做法描述，非提示词逐字稿）

```

通读我全部生意的基础设施账单：[GPU / 服务器 / 备份 / 对象存储 / 域名 / Claude 订阅]。

逐项回答：这项现在每月花多少？有没有更便宜的替代方案（换供应商、换套餐、改保留策略、清掉不用的）？

每项给出前后对比：现在多少钱 → 换成什么 → 之后多少钱。

最后汇总一张表：分项节省 + 合计，并标出哪些节省是一次性的（如积分、首年优惠）、哪些是每月持续的。

```

关键不在话术，在三条结构：① 全量账单，不只审一张——GPU、服务器、备份、存储、域名、订阅六项都要过；② 每项都要前后对比价，节省数来自“换成什么”，不是凭空估算；③ 一次性节省与持续节省分开标，积分、首年优惠不能按月复利算。

中国读者怎么迁移

方法可迁移，数字不可照搬：普通读者没有每月 $36,000 的 GPU 账单，但同一套“全量账单审计”可用在自己的订阅与云服务上——云服务器、对象存储、域名、各类 SaaS 订阅，让智能体逐项审“现在多少钱、有没有更便宜的替代、换了能省多少”，再逐项切换；但要注意：① 国内云厂商（阿里云、腾讯云、华为云）与美国供应商的套餐结构不同，替代方案要按国内实际价格查；② 备份保留期、存储生命周期这类策略改动前先确认业务影响，别为省钱丢数据；③ 作者本人是公开账目的独立开发者，方法可学，$34,000 这个数是他的体量，别当成普通人的预期。
